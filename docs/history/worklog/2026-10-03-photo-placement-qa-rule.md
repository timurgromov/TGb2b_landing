# Photo placement QA rule — 2026-10-03

## Decision

Added an always-on project rule for every photo insertion, replacement and crop. Acceptance now requires visual review of every changed photo in every real container and route variant on mobile, desktop and breakpoint-adjacent widths.

The review covers the complete composition: head and hair, hands and meaningful objects, intentional breathing space, focal point, overlays, masks and aspect ratio. Sliders and galleries must be checked frame by frame rather than only on the first slide.

## Boundary

This is a project workflow rule only. No public markup, styles, media or runtime behavior changed, so no site deploy is required.
